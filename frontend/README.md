# Frontend

Phần giao diện dự kiến sử dụng React. Chưa khởi tạo ứng dụng hoặc cài thư viện.

## Trước khi viết code

1. Chốt chức năng và quyền của Admin, ứng viên, nhà tuyển dụng.
2. Duyệt danh sách màn hình tại `../docs/ui/README.md`.
3. Vẽ wireframe và xác định trạng thái đang tải, rỗng, lỗi, thành công.
4. Thống nhất dữ liệu và API với backend.

Sau đó khởi tạo React trên nhánh tính năng và bổ sung lệnh cài đặt/chạy đã kiểm tra.
Giai đoạn dựng giao diện có thể dùng dữ liệu giả lập, ghi rõ kết quả AI minh họa.
Phân quyền ở giao diện không thay thế việc kiểm tra quyền ở backend.
